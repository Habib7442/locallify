# PRD — Locallify Global Rebrand & Repositioning (v3)

**Brand:** Locallify — global software studio
**Site (for now):** https://locallify.in/  *(global domain to be updated manually later)*
**Version:** 3.0 · **Last updated:** 2026-07-13 · **Status:** Ready for design + build

---

## 1. Objective

Reposition Locallify from an India-focused "digital storefront" service into a **global software studio** that designs and builds **custom software, web apps, and mobile apps** — with **SEO + GEO** engineered in so clients get found on Google *and* in AI search. Redesign the website to a professional, global standard, priced in **USD**.

**Shifts in this version:**
1. **Offering:** productized "digital storefronts for local businesses" → **custom software / web apps / mobile apps + SEO + GEO**.
2. **Positioning:** local (India) → **global software studio**.
3. **Design:** casual/edgy → clean, credible, modern studio.
4. **Pricing:** INR → **USD**, with a global-friendly model (see §7).
5. **Domain:** **keep `locallify.in` for now**; global domain (`.co`/`.com`) updated manually later.

## 7. Pricing Model (recommended — global)

**Best global model = Hybrid: productized build packages + custom project quotes + a monthly Care & Growth retainer. All in USD.** (Deliberately *not* hourly-as-primary — hourly caps income and reads "freelancer"; keep it only for out-of-scope work.)

**A. Build — one-time, fixed-scope starting prices (removes "how much?" friction):**

| Package | From (USD) |
|---|---|
| Landing / marketing site (SEO + GEO) | from **$600** |
| Business website, multi-page (SEO + GEO) | from **$1,800** |
| Web app / MVP | from **$6,000** |
| Mobile app (iOS + Android) | from **$9,000** |
| Custom software / larger builds | **custom quote** (milestone-based) |

**B. Care & Growth — monthly retainer (your recurring-revenue engine):**

| Plan | From (USD/mo) | Includes |
|---|---|---|
| **Care** | **$99/mo** | Hosting, maintenance, updates, monitoring, support |
| **Growth** ⭐ | **$399/mo** | Care + ongoing **SEO + GEO** + content + monthly reporting |
| **Scale** | **$899/mo** | Growth + priority dev hours + analytics/ads |

**C. Out-of-scope / ad-hoc:** ~**$40/hr** (or a day rate) — secondary only.

- **Payment:** projects on **milestones** (e.g., 50% start / 40% on delivery / 10% at launch); retainers monthly. **USD** via Stripe/wire; global.
- **Why this model:** fixed packages sell fast worldwide and set clear value; custom quotes capture bigger deals; the retainer — especially **SEO + GEO, which is inherently ongoing** — is the stable recurring base. This scales far better than hourly.
- Numbers are **indicative starting points** — tune to your cost base + target region; going *professional/global*, don't race to the bottom on price.

## 8. SEO + GEO (offering AND the site itself)

Build this into both the client work and Locallify's own site:
- **SEO:** clean semantic HTML, fast Core Web Vitals, metadata, sitemaps, schema.org structured data, internal linking, local/geographic targeting where relevant.
- **GEO (Generative Engine Optimization):** content and structure optimized so the business surfaces in **AI answers** (ChatGPT, Perplexity, Google AI Overviews, Gemini) — clear factual content, structured data, entity clarity, authoritative sourcing, `llms.txt`-style machine-readability.
- Make **"SEO + GEO built in"** a headline differentiator on the site — few dev studios offer it.

## 10. Conversion & Funnel

- Persistent **WhatsApp** + **Book a call** + a short **project-inquiry form** (name, company, country, project type, budget range, WhatsApp/email).
- **Meta Pixel + GA4** so you can run global ads and optimize for qualified inquiries.
- Fast load (LCP < 2.5s), mobile-first, strong OG image for link/ad previews.

## 11. Technical Requirements

- **Stack:** modern, fast marketing site (Next.js on Vercel or similar). CMS optional for case studies/blog (blog fuels SEO + GEO).
- **SEO/GEO baked in** (see §8): schema.org, sitemap, metadata, Core Web Vitals, machine-readable content.
- **Config-driven:** currency, pricing, WhatsApp number, contact easy to change.
- **Domain:** stay on **locallify.in** for now; when the global domain is chosen, migrate + 301-redirect (manual, later).
